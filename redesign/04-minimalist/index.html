Building作品

Most of what I build now lives inside Novada Labs. AgentRecall — persistent memory for AI agents, so corrections actually stick — is the flagship: 313 stars on GitHub and more than 6,400 installs a month. Alongside it sits AAM (Agent Autonomous Mode), an orchestration framework for autonomous agent teams built around one rule: the reviewer is never the author. Plywood Protocol compiles plain-language instructions into executable standard operating procedures — validated through a blinded randomized controlled trial, not just claimed. Novada MCP is the integration layer: one MCP server exposing 40+ tools across 13 platforms. And Novada Proxy MCP gives agents reliable web access, backed by 464 automated tests. Five products, one thesis: an AI system is only as good as the discipline that keeps it honest in production. 如今我做的大部分东西都在 Novada Labs 里。AgentRecall——为 AI Agent 打造的持久记忆系统，让纠正真正被记住——是其中的旗舰产品：GitHub 313 颗星，每月 6,400+ 次安装。与之并列的是 AAM（Agent Autonomous Mode），一个多智能体编排框架，只遵循一条规则：审阅者永远不是执行者本人。Plywood Protocol 把自然语言指令编译成可执行的标准作业流程——经过盲测随机对照试验验证，而不只是自吹。Novada MCP 是集成层：一个 MCP 服务器，覆盖 13 个平台、40 多个工具。Novada Proxy MCP 则为 Agent 提供稳定的网络访问能力，464 个自动化测试兜底。五个产品，一个信念：AI 系统的好坏，取决于让它在生产环境里保持诚实的那套纪律。
